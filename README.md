# SwissWeb 🛠️

A comprehensive collection of web-based utilities and tools designed to streamline your workflow and boost productivity. SwissWeb provides a suite of essential developer and productivity tools that run entirely in your browser.

## 🚀 Live Demo
You can access the live version of SwissWeb at: [https://b1krams.github.io](https://b1krams.github.io)

## ✨ Features

SwissWeb includes a variety of powerful utilities:

- **⚖️ Decision Maker**: Make choices easier with an interactive decision matrix. Weight your priorities and find the objective winner.
- **🖼️ Image Tools**: Quickly process, convert, and manipulate your images right in the browser.
- **{" "} JSON Formatter**: Format, parse, minify, and validate your JSON data structures with ease.
- **📝 Markdown Editor**: Write, edit, and preview markdown with real-time rendering capabilities.
- **🧠 Mind Map**: Visualize your thoughts, brainstorm, and organize complex ideas graphically.
- **📰 News Reader**: Stay updated with the latest headlines and articles in a clean interface.
- **📄 PDF Utilities**: Merge, split, compress, and manipulate your PDF documents locally.
- **⏱️ Pomodoro Timer**: Boost your focus and productivity with the proven Pomodoro technique.
- **❓ Quiz Maker**: Create, test, and take interactive quizzes for learning and assessment.
- **📡 Signal Scope**: Real-time audio signal visualizer with waveform and frequency spectrum views.
- **💰 Finance Engine**: Investment comparison engine with post-tax compounded wealth projections.

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript
- **Styling**: Vanilla CSS, Tailwind CSS (for some tools)
- **Interactivity**: Alpine.js (for some tools)
- **Deployment**: GitHub Pages

## 📂 Project Structure

- `/decide`: Decision Maker tool
- `/image`: Image processing tools
- `/json`: JSON formatting and validation
- `/md`: Markdown editing and preview
- `/mind`: Mind mapping tool
- `/news`: News aggregator
- `/pdf`: PDF manipulation utilities
- `/pomo`: Pomodoro productivity timer
- `/quiz`: Interactive quiz builder
- `/signal`: Real-time audio signal visualizer
- `/finance`: Investment comparison engine

## 💻 Local Development

To run SwissWeb locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/b1krams/b1krams.github.io.git
   ```
2. Navigate to the project directory:
   ```bash
   cd b1krams.github.io
   ```
3. Open `index.html` in your favorite web browser.
